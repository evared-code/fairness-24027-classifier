TR 24027 Fairness Classifier

Classifies design decision options by their primary source of potential bias and the specific bias type, following ISO/IEC TR 24027:2021: data, human cognitive, engineering, or none. Each option is asked several times per model, and up to three models answer independently, so you get a confidence for every label and a measure of how far the models agree.

Your keys stay with you

The tool runs in your browser. API keys and data go straight to the model providers you choose, or through this site's API proxy only if you choose it.

Protocol

  1. Load decisions and options

    Upload one or more JSON files. Each option is classified separately; a decision without options is classified as a whole.

    or use an example:
    Input file format 
    {
  "title": "My study",                       // optional
  "context": "Describe the system ...",      // optional, sent with every question
  "decisions": [
    {
      "id": "D1",                              // required, unique
      "question": "How to ...?",               // required
      "source": "Practitioner",                // optional, groups results (e.g. voice)
      "category": "Trust and safety",          // optional
      "drivers": ["Trust (+)"],                // optional, applies to all options
      "options": [                             // optional
        { "id": "D1-O1", "text": "Option A",
          "drivers": ["Transparency (++)", { "name": "Bias", "effect": "N" }] },
        "Option B"                             // or just text
      ]
    }
  ]
}

    Decision drivers are optional: the quality attributes (forces) a decision or option affects, with an optional effect: ++ strongly supports, + supports, N neutral, - hurts, -- strongly hurts. Drivers on a decision apply to all its options.

    Download the example file to use as a template.

  2. Choose models and enter API keys

    Pick any provider and model for each row and give it the name you want to see in the report. Use at least three models, ideally from different providers, for the agreement statistics. Check key confirms the key works and lists the models it can use. OpenAI-compatible covers services such as OpenRouter, DeepSeek, Groq, Mistral or a local server; enter its base URL.

    Route to the providers

  3. Set the sampling

    Prompt and label definitions

    The default definitions paraphrase the bias sources in ISO/IEC TR 24027:2021. Check the wording against the standard before you publish; the report records exactly what was used.
